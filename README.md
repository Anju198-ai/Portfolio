## 🧐 Overview

This repository contains the source code for my personal portfolio website. Built with a mobile-first approach, it serves as an interactive platform to highlight my experience in full-stack web development, frontend design, backend logic, and database management.

---

## ✨ Key Features

- 📱 **Fully Responsive:** Optimized for seamless viewing across smartphones, tablets, and desktop displays.
- 🎨 **Modern UI/UX:** Clean typography, intuitive card layouts, and custom hover effects.
- ⚡ **Interactive Elements:** Smooth navigation, dynamic UI components, and mobile menu toggles.
- 💼 **Project Showcase:** Highlights key web applications with direct links to live demos and repositories.
- 🛠️ **Skill Matrix:** Clear breakdown of frontend, backend, and database technologies.

---

## 🛠️ Tech Stack

- **Markup & Structure:** HTML5
- **Styling & Layout:** CSS3, Flexbox, CSS Grid, Bootstrap
- **Scripts & Logic:** JavaScript (ES6+)
- **Core Skills Highlighted:** C#, ASP.NET Core MVC, SQL Server, Git
